# Puertos y Servicios Escenciales

## Puerto | Servicio

**- 20 FTP(Data):** Utilizada para la transferencia de datos de archivos en el protocolo FTP

**- 21 FTP(Control):** Utilizada para establecer y controlar las conexiones FTP, coomo inicar sesion y enviar comandos

**- 22 SSH:** Permite establecer conexiones remotas seguras y administrar servidores mediante una conexion cifrada

**- 23 Telnte:** Permite conexiones remotas a otros equipos, pero transmite la informacion sin cifrado, por lo que actualmente es considerado inseguro

**- 26 SMTP:** Utilizado principalmente para el envio de correos electronicos entre servidores de correo

**- 53 DNS:** Utilizado para resolver nombres de dominio, por ejemplo, al buscar alguna pagina como google.com este puerto la traduce a una direccion IP accesible para los dispositivos

**- 80 HTTP:** Utilizado para la comunicacion web de las paginas y servicios web, sin cifrado

**- 110 POP3:** Permite que un cliente de correo electronico descargue mensajes desde un servidor 

**- 443 HTTPS:** Utilizado para servicios web mediante HTTP sobre TLS propocionando cifrado y proteccion de la comunicacion

**- 3306 MYSQL:** Utilizado para establecer conexiones con servidores de bases de datos
